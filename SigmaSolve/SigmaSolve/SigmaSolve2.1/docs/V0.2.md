# SigmaSolve v0.2

Version 0.2 adds deployable research infrastructure:

- environment doctor for Lean, Lake, Docker, Z3, SymPy, and mpmath;
- Dockerized Lean-capable runtime with resource isolation;
- Lean source dependency indexing and symbol search;
- SQLite theorem memory with evidence and dependency fields;
- explicit representation portfolios and transfer obligations;
- SymPy symbolic candidate checks;
- Z3 SMT-LIB satisfiability and countermodel backend;
- mpmath finite zeta-zero scan whose limitations are machine-recorded;
- Riemann Hypothesis problem contract.

These additions make the missing backends deployable. They do not turn bounded computation into a proof of RH and do not install external binaries into an already-running host where package installation is unavailable.
