# Claim maturity

```text
REGISTERED
→ FORMALIZED
→ IDENTITY_VERIFIED
→ POSITIVITY_VERIFIED
→ INDEPENDENCE_PASSED
→ CLEAN_REPLAYED
→ INTERNALLY_REPRODUCED
→ INDEPENDENTLY_REPRODUCED
```

No later state may be inferred from an earlier state. In particular, formal equivalence is not RH, and a positive-looking representation is not a proof of identity or positivity.
