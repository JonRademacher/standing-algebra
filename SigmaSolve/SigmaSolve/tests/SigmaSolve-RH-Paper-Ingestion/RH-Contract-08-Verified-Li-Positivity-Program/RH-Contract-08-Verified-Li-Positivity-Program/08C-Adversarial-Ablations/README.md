# 08C — Adversarial ablations

Before proof development, attack each candidate through:

- finite-dimensional operator models;
- projection/cross-term perturbations;
- missing trace-class assumptions;
- normalization changes;
- finite truncation and tail-sign tests;
- dependency-cycle detection;
- hidden equivalence detection;
- limit/interchange removal.

A counterexample eliminates only the tested formulation and assumptions, not the whole candidate family.
