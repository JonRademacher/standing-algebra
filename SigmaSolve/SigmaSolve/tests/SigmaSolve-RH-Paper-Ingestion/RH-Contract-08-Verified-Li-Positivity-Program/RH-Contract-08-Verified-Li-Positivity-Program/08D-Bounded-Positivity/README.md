# 08D — Bounded Li positivity

Research implications of the form:

\[
\text{RH verified through height }T
\Longrightarrow
\lambda_n\ge0\quad(n\le f(T)).
\]

This branch cannot prove RH. Its purpose is to produce explicit, rigorous, scope-bounded positivity certificates and a benchmark connecting zero verification with Li coefficients.

Every result must state:

- exact verified zero height;
- zero-count source and certification method;
- explicit function `f(T)` and constants;
- zero-tail estimate;
- Li normalization;
- interval/exact arithmetic method;
- theorem status and provenance.
