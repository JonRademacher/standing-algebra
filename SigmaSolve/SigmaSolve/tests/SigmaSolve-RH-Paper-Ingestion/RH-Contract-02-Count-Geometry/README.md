# RH Contract 02 — Count Geometry

This is an **additional child contract**, not an upgrade/replacement of the RH Paper Ingestion contract.

The ingestion contract answers: **what survives from the manuscripts?**

This contract answers: **can the strongest surviving bounded theorem be bound to exact zeta-zero counting objects and then lifted to an exact RH equivalence?**

Keep both folders. Suggested repository layout:

```text
SigmaSolve RH Paper Ingestion/
├── ...existing ingestion artifacts...
├── SigmaSolve-RH-v0.4-integrated-run/
└── RH-Contract-02-Count-Geometry/
    ├── problem-contract.json
    ├── methodology-contract.json
    ├── derivation.md
    ├── formalization-plan.json
    ├── result.json
    └── MANIFEST.sha256
```

The contract does not claim that the all-height equality has been proved.
