# RH-C07B — Quotient / Inverse Binding

This is the next scoped continuation under Contract 07. It is not Contract 08.

## Objective

Repair or reject the `E_S^{-1}` typing gap identified in C07A, then determine what remains before equations (4.11)–(4.14) and (5.8)–(5.10) can be replayed as well-typed operator identities.

## Outcome

The visible candidate-paper notation is not sufficient to define a literal inverse on Schwartz functions. However, the inverse can be **conditionally repaired** at the Hilbert-space level if the inner product used to define `L2(X_S)` makes `E_S` an isometry and its stated dense range is accepted. An isometry has closed range; dense + closed range is the whole target. Thus the extension is unitary and has a unique bounded inverse.

This repairs the type shape without validating the external construction itself. The remaining burden is to verify that the quoted external result actually supplies the stated Hilbert-space construction and that every later formula is independent of representative before using the inverse notation.
