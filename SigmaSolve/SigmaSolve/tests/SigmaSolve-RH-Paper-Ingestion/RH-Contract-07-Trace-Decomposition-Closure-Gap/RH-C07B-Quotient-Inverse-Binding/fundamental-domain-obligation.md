# Fundamental-domain obligation

The S-unit group `O_S^*` is countable and infinite. The proof of T3 requires one measurable set `I_S` satisfying, modulo null sets,

\[
J_S=\bigsqcup_{\xi\in O_S^*}\xi I_S.
\]

The later equal-summand proof additionally requires:

1. the action is measurable;
2. the translates are pairwise disjoint modulo null sets;
3. the union covers `J_S` modulo null sets;
4. additive measure transforms by the correct module;
5. the module is `|xi|_S=1` for S-units;
6. the integrand transformation preserves the character and all cutoff conditions.

C07A established the algebraic reason `O_S^*` is infinite and the product-formula reason `|xi|_S=1`. C07B does not yet independently construct `I_S`. Therefore the repeated-summand proof remains blocked at this exact point even after repairing `E_S^{-1}`.
