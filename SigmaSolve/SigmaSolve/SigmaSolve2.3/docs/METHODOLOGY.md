# Integrated Methodology

SigmaSolve v0.4 adds an executable methodological control plane around proof search.

## GEGA pass

For each problem, reconstruct:

1. existence: what objects and claims actually exist;
2. identity: which target, artifact, or theorem remains invariant;
3. relations: dependencies, contradictions, supports, and transfer edges;
4. environment: formal library, source corpus, numerical or institutional setting;
5. boundaries: scope, authority, representation, applicability, and capability limits;
6. realizations: candidate proofs, models, encodings, and experiments;
7. consequences: what each realization would establish or destroy;
8. updated geometry: state after evidence and correction;
9. missing structures: the minimum absent bridges, witnesses, or operators.

GEGA generates and localizes candidate structure. It does not certify truth.

## MSI-UCK gates

Before promotion, check applicability, correctness, evidence, provenance, authority, privacy, safety, capability, currentness, no-regression, residuals, survivor preservation, reopening, and completion.

## OCEL execution

Use state-before-action and preserve:

`UNDERSTOOD != PLANNED != ATTEMPTED != EXECUTED != TERMINAL-STATE-VERIFIED`.

Delegated work requires an executable context package. Returned work is a state delta and must be reconciled; it does not overwrite parent state automatically.

## CCAR and epistemic type

Preserve observation, source claim, inference, reconstruction, hypothesis, analogy, prediction, formal claim, validation, and canonical state as distinct types. Compression cannot promote a type.

## Formal work

ROO and the Rademacher Standard require exact targets, explicit definitions, complete dependencies, necessity/sufficiency, and residual localization. CDPI tests portability only relative to a declared equivalence profile and preserved dependency carriers.

## Scholarly work

Maintain prior art, exact citation support, internal versus independent reproduction, negative and null results, artifact lineage, contribution provenance, and claim maturity. Verification is not validation.
