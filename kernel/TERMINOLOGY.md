# Terminology

| Term | Operational meaning |
|---|---|
| Current state | Reconstructed status supported by observed repository state and cited sources. |
| Checkpoint | Versioned snapshot with exact source revisions, validation, residuals, and rollback. |
| Provenance | Origin, author/contributor, path, revision, and transformation lineage of an artifact or claim. |
| Dependency edge | A consequence-bearing relation supported by an explicit source or reconstruction witness. |
| Survivor | A candidate not eliminated by declared admissibility constraints and witnesses. |
| Selection | Authorized choice among survivors; distinct from filtering or elimination. |
| Failure shape | Reusable minimal generating structure for an observed failure, scoped to evidence. |
| Discovery shape | Reusable minimal structure for a validated discovery, scoped to evidence. |
| Candidate improvement | Proposed delta that has not yet been accepted as canonical. |
| Verified | Passed the specific named computational or review check; never a generic claim. |
| Reopening | Reconsidering a prior decision when a documented condition or new evidence invalidates closure. |
| Canonical | Accepted repository state at a named checkpoint, not a hidden model state. |
