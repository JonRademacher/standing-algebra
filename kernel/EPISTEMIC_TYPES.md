# Epistemic Types

Use explicit labels where a statement affects decisions or continuity:

- **Observation:** directly inspected state or tool output.
- **Participant statement:** claim made by a contributor/user.
- **Source claim:** statement in an identified authoritative source.
- **Inference:** consequence drawn from observations/source claims.
- **Reconstruction:** best current account derived from provenance-bearing artifacts.
- **Hypothesis:** falsifiable candidate not yet established.
- **Analogy:** structural resemblance, not identity or entailment.
- **Fiction/imagination:** illustrative construction, not evidence.
- **Prediction:** future-oriented claim with stated assumptions.
- **Computational verification:** result of a named executed tool/check.
- **Independent reproduction:** repeated result by an independent party.
- **External validation:** domain-appropriate validation beyond this repository.
- **Canonical state:** accepted state at an identified checkpoint.
- **Unresolved:** materially incomplete, conflicting, unsupported, or unverified.

Do not silently promote a statement between types. A build result does not
prove source fidelity, theorem correctness beyond the encoded statement,
originality, external validity, or production fitness.
